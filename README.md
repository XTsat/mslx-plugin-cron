# mslx-plugin-cron · 定时任务绑定

MSLX 开服器的「多服定时任务」插件：同一个任务可以绑定**多台服务器**统一执行，并把宿主的「服务器绑定任务」一键迁移到插件内接管。

```
定时任务（插件）            宿主任务（MSLX 内建）
  ├── 任务 A ── 服务器 1,3      ├── 自动备份 ── 实例 4      （可迁移）
  ├── 任务 B ── 服务器 2        ├── 重启服务器 ── 实例 6    （可迁移）
  └── 任务 C ── 服务器 1,2,4    └── 备份存档 ── 实例 5,6    （可迁移）
```

> 环境要求：MSLX ≥ 1.7.0（插件使用 v1.7 起提供的实例生命周期 / 控制台 / 备份服务接口）。

## 功能

- **任务绑定多服务器**：任务与绑定分离，创建时可勾选多台服务器、也可暂不选择直接保存，稍后编辑再绑定；一个任务在所有选中服务器上按同一 cron 表达式执行。
- **导入宿主任务**：一键把宿主「服务器绑定任务」迁移进插件——点击导入后**先展示将导入的任务清单**，确认后才导入。
- **增量导入**：已导入过的宿主任务自动跳过，重复点击只会导入新出现的任务；已彻底接管的宿主任务不会再次重走归并，你在插件侧停用、修改或删除的任务不会被重新创建。
- **避免双跑**：导入时先持久化原启停状态、再逐个禁用接管宿主任务，禁用失败的任务保持待接管状态、下次迁移自动重试，避免两边同时执行；插件卸载时宿主任务**保持接管状态不自动还原**，如需还原请使用页面「**还原宿主任务**」按钮（仅管理员，按迁移记录恢复原启停状态，**还原后插件调度自动停止**，适用于彻底卸载前），卸载同时会**取消正在执行的任务**（含「立即执行」）。
- **删除跟随清理**：服务器被删除后，插件会自动移除该服务器在所有任务中的绑定（约一分钟内完成）；任务即使因此失去全部绑定也会保留，绑定列表显示为空，可重新编辑绑定服务器后恢复调度。
- **失效绑定可见可清（兜底）**：若自动清理暂未触发（如宿主服务器清单不可用），任务列表会以「已删除」标记失效绑定；编辑任务时可取消勾选或一键移除失效绑定，不再残留无法删除的绑定。
- **复制任务**：编辑弹窗内点「复制任务」即可把任务复制为**不带任何绑定服务器**的新副本（副本归属创建者、始终可见），勾选你有权限的服务器保存后独立调度——用于无法直接修改共享任务时获得自己的版本。
- **权限**：普通用户仅能查看自己创建的任务、或自己至少有一台绑定权限的服务器所关联的任务（列表按权限过滤服务器，只能看到自己有权限的绑定）；**含你无权限服务器的任务无法直接修改**，请改用「复制任务」创建自己的副本；删除或整体启停共享任务要求至少一台绑定有权限，涉及无权限服务器的操作会记录警告日志；shell 任务的创建、执行、复制与启用仅限管理员。

## 使用

1. 打开 **定时任务** 页面。
2. **新建任务**：填写任务名、cron 表达式、命令/脚本内容，可选勾选要绑定的服务器（不选也可保存，创建后随时编辑绑定），保存后即开始调度。
3. **导入宿主任务**：点击「导入宿主新任务」→ 弹出预览面板，逐条确认将导入的任务 → 点「确认导入」完成迁移。
4. **复制任务**：打开任务的编辑弹窗点「复制任务」→ 生成不带绑定服务器的新副本 → 勾选你有权限的服务器后保存，即可拥有独立的同款任务。
